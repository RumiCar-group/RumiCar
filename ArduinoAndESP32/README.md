Arduino NanoおよびESP32のCMに対応したRumiCarのExercise集です。

ハンズオンで使うExercise（Exercise、Exercise-1.1〜4.2）は、RumiCarライブラリ（v0.5.0以降。Exercise-4 と解答例 Exercise-4.x-Answer、AIへの約束ファイル AGENTS.md はv0.5.0から）のスケッチ例として配布しています。Arduino IDEのライブラリマネージャで「RumiCar」をインストールし（[導入方法](./Libraries/README.md)）、「ファイル」→「スケッチ例」→「RumiCar」から開いてください。以前このフォルダにあった同じ内容のファイルは、二重管理を避けるため削除しました（ソース：[RumiCar-lib/examples](https://github.com/RumiCar-group/RumiCar-lib/tree/main/examples)）。

Exercise-A2.3やExercise-A3.1など数字の後にAとBが付いているExerciseは上級編です。モーターをゆっくりと回転させたりスムーズに回転させる、難易度が少し高めのプログラムです。イベント中には使いませんが挑戦してみてください。
