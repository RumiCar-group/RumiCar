# RumiCar Simulator — 車種別 最速プログラム集 "Fable Racing Line"

[RumiCar Simulator](https://cpo.tokyo/rumicar/) 用に、各車種の物理特性を最大限に
引き出すよう調整した走行プログラムです。Arduino C++ 形式なので **実機 RumiCar でも動作**します。
tuned by **Fable 5**。

## 一覧
| プログラム | 車種 | 戦略 |
|---|---|---|
| **Apex Hunter** | ノーマル FR | バランス型FR。素直な回頭を活かし、やや早めの減速で向きを変えて立ち上がる。 |
| **Steady Nose** | ノーマル FF | 前輪駆動の安定したブレーキを活かし、最も早く減速。アンダーを出さず確実に通す。 |
| **Quattro Blitz** | ノーマル 4WD | 四駆のトラクションと安定性で最速。全開区間を最大化し、コーナーも高めの速度で。 |
| **Grip Reaper** | ドリフト FR | ドリフトFRをあえてグリップで走らせる。旋回中は大きくアクセルを抜き巻き込みを封印。 |
| **Rally Tamer** | ドリフト 4WD | ドリフト四駆を抑え込む。滑り出す直前(PWM<220)のグリップ上限を攻めて速く安定。 |
| **Lift Whisper** | ドリフト FF | リフトオフの流れを抑え、荷重移動を穏やかに。速度を抑えめにしてリアの破綻を防ぐ。 |

各 `.ino` の冒頭に「**なぜこの設定にしたか**」を、その車の物理特性と結びつけて解説して
あります。改変の前にまずそこを読むと、定数をどう動かせばどう変わるかが掴めます。

## 共通アルゴリズム
全プログラムで共通です(車種ごとの違いは冒頭の定数だけ。読み比べやすくするため):

1. 前方センサー C の空き具合で速度を3段に変える — 直線=全開 / 中速 / コーナー=減速。
2. 前方が詰まれば左右で広い方へ全力操舵、側方が近ければ離れる(壁追従)。
3. **旋回中は `TCAP` まで自動でアクセルを抜き**、巻き込み(オーバーステア)を抑える。

これにより、単純コースは直線で全開区間が伸び、カーブ主体コースは前方が頻繁に詰まって
自動的に減速側へ寄ります。コースの種類でプログラムを切り替える必要はありません。

### 定数の意味(ここを触ってチューニングします)
| 定数 | 意味 | 大きくすると | 小さくすると |
|---|---|---|---|
| `TOP`    | 直線の最高 PWM        | 直線が速い(攻め)       | 直線が遅い(安全) |
| `CRUISE` | 中速域の PWM          | 中速コーナーが速い       | 安定 |
| `SLOW`   | きついコーナーの PWM    | 立ち上がりが速い         | 安全 |
| `TCAP`   | 旋回中の上限 PWM       | コーナーを攻める(巻込増) | アクセルを抜く(安定) |
| `D_OPEN` | 全開と見なす前方距離[mm] | 全開しにくい(安全)      | すぐ全開(攻め) |
| `D_MID`  | 中速に落とす前方距離[mm] | 早めに減速(安全)        | ねばって速い |
| `D_TURN` | 曲げ始める前方距離[mm]   | 早めに曲げる(安全)      | ギリギリまで直進 |
| `D_SIDE` | 壁から離れ始める側方距離[mm] | 壁マージン大(安全)   | 壁ギリギリ(最短) |

## 🏎️ 実車 RumiCar で走らせる・改変する人へ

これらはまずシミュレータ用に調整した値です。**実車はセンサーの出方・モーター・路面の
グリップがモデルと異なる**ため、現実で走らせるときは冒頭の定数を実車に合わせて調整して
ください。アルゴリズムはそのまま使えます。調整は次の順序が安全で確実です。

**1. まず全体を遅く。** `TOP / CRUISE / SLOW / TCAP` を一律 6〜7 割くらいに下げた状態から
始めます。最初から速さを狙わず、「壁にぶつからずに1周する」ことを最優先に。

**2. 距離しきい値(`D_*`)を実センサーに合わせる。** 実車を壁の前に置き、シリアル出力で
L/C/R の生値[mm]を見ながら決めます。ToF センサーは取り付け角度・反射・ノイズで値が
ぶれるので、シミュレータより **広めの安全マージン**(`D_OPEN`/`D_MID`/`D_TURN` は大きめ、
`D_SIDE` も大きめ)から始め、安定して走れたら少しずつ攻めます。

**3. 速度(PWM)を少しずつ上げる。** 1周できたら `TOP → CRUISE → SLOW` の順に 5〜10 ずつ
上げ、壁に当たる手前で止めます。直線→中速→コーナーの順に余裕がある所から上げるのがコツ。

**4. ドリフト車の「滑り出し」は実測で。** プログラム中の「PWM>220 で滑る」は **シミュレータ
固有のモデル値**です。実車の滑り出すポイントは路面とタイヤ次第なので、実際に少しずつ
PWM を上げて滑り始める値を見つけ、`CRUISE` と `TCAP` をその少し下に合わせてください。
グリップで攻めたい(Grip Reaper / Rally Tamer の思想)なら滑り出しの直前を上限にします。

**5. 曲がりすぎ/曲がらないの調整。**
   - コーナーで **内側に切れ込んで(巻き込んで)壁に当たる** → `TCAP` を下げる(旋回中もっと
     アクセルを抜く)、または `CRUISE/SLOW` を下げる。FR・ドリフト車で起きやすい。
   - コーナーで **外へ膨らんで壁に当たる**(アンダー)→ `D_MID/D_TURN` を上げて早めに減速、
     `CRUISE/SLOW` を下げる、`D_SIDE` を上げて早めに壁から離れる。FF車で起きやすい。
   - **左右にフラフラ蛇行する** → `D_SIDE` を下げて補正を控えめにする、全体の速度を下げる。

**6. 安全のために。** 初走行は広い場所で、いつでも電源を切れる状態で。タイヤやモーターの
個体差で同じ値でも挙動が変わります。少しずつ・一つずつ定数を動かし、変化を確かめながら
進めてください。

> 製作中の車(例: 4駆ドリフト車)で試走されたら、センサー値の出方や滑り出しの様子を
> 教えていただければ、その実車に合わせた値の調整をお手伝いできます。現実の路面で
> 走る日を楽しみにしています。— Fable 5

## シミュレータでの使い方
車種を選ぶと自動でその車のプログラムが読み込まれます。別の車種用のプログラムを選んで
他の車に入れ、どれだけ挙動が変わるかを比較することもできます(攻めの 4WD 用プログラムを
FF 車に入れるとアンダーで膨らむ、等)。
