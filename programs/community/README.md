# programs/community — 利用者が投稿した走行プログラム

[RumiCar Simulator](https://www.rumicar.com/simulator/) で改変したプログラムを **別名で** ここに
投稿する場所です。シミュレータは起動時にこのフォルダを読み込み、各車の「走行」メニューの
**「🌐 みんなの投稿」** に並べます。誰でも選んで走らせ、再利用できます。

## 投稿のしかた
1. シミュレータでプログラムを編集し、走らせて納得いくまで調整する
2. その車の「🌐保存」ボタンを押し、保存名を入力する
3. GitHub の新規ファイル作成画面が開くので、そのままコミット → プルリクエストが作成されます
   (書込権限が無い場合は自動で fork されます)
4. マージされると、全利用者の「🌐 みんなの投稿」に並びます

## ルール (ゆるく)
- **上書きせず別名で**追加してください (同名でもファイルを増やせます)
- 不要になったファイルの**削除は GitHub 上**で行います
- 実車でも動くよう Arduino C++ (.ino) 推奨。Python (.py) / JavaScript (.js) も可
- 走行 API: `RC_setup()` / `RC_drive(FORWARD, pwm)` / `RC_steer(LEFT/CENTER/RIGHT)` /
  `sensor0/1/2.readRangeSingleMillimeters()`

## 戦術プログラム — 「速さだけが競争ではない」(by Fable 5)

複数台モードで「他車を障害物にする」をONにすると、レースの駆け引きが生まれます。2台レースの
実測から得た戦術プログラムです(各 .ino の冒頭に「なぜ」を詳述):

- **blocker-area-denial.ino** … 進路妨害/エリア占有。前に出たら、相手のラインを**低速で占有**して
  抜かせない。派手なドリフトや左右の振りは逆効果(自分が動いてラインを空ける)で、**同じラインを
  遅く塞ぐのが最強**。狭いコースでは追い越しロジック相手でもほぼ完封、広いコースでは相手を遅い
  外側ラインへ追いやる効果に変わる。
- **overtaker-passing.ino** … その対抗手。前車の先の“横の空き”を突いて回り込む。**広いコースでは
  抜けるが狭いコースでは抜けない**——コース幅が攻守の勝敗を分ける、という学びになる。

### 実測まとめ(40秒で追走車が進んだ距離。短い=ブロック成功)
| コース | 素直な追走 vs 単純ブロック | 賢い追走(追越し) vs 単純ブロック |
|---|---|---|
| ナローゲート(狭) | 3%(完封) | 3%(抜けない=ブロッカーの勝ち) |
| オーバル(広) | 7%(完封) | 99%(抜ける=オーバーテイカーの勝ち) |

→ **特定の条件(狭い・相手が追い越しを知らない)では、遅い車でも戦術で勝てる。** 速さで劣る
車種・状況でも、特性と戦略を選べば有利に戦える——自分のロジックを考える切っ掛けにどうぞ。

## 戦術の続き — 「前に出る」リスクと「速いライン」の限界(数値つき)

- **blocker-v2-getahead.ino** … 「まず前に出る→出たら守る」2段階。実測: ペース優位×狭い道では
  前に出て相手を**基準比30%**に封殺。だが同等ペースでは前に出られず無理な追越しでクラッシュ。
  → **ブロックの前提は“前に出る”ことで、それ自体が難所(位置取りが王様)**。
- **racing-line-speed.ino** … アウト-イン-アウトの研究。幾何ラインは3値操舵では**0/10完走**(外へ
  commitして壁)。速度プロファイル版でも基準の**98.8%**(速い流れるコースだけ僅かに勝つ)。
  → **反応制御では壁追従が既にほぼ最適。理屈のライン≠ロボットのライン。**

### 条件で変わる「強い車・強い戦略」(まとめ)
| 状況 | 有利 | 理由(実測) |
|---|---|---|
| 乾いた高速・直線多い | 4WD | トラクション/最高速。立ち上がり全開が効く |
| 乾いたタイト下り(峠) | 軽量FR | 軽さで俊敏。重い4WDは膨らむ |
| 雨(低グリップ)で攻める | FF・安定車 | テールの出る車はスピン自滅、アンダーは生き残る |
| 狭い道で前に出た後 | ブロッカー | 速さ不要。占有で相手を封殺(30%) |
| 速い流れるコース | 速度ライン/4WD | 早い立ち上がりが効く |

**速さで全勝はできない。条件ごとに有利な車種・戦略があり、それを引き出すのが面白さ。**

## ドリフトの活かし方 — 速さ・ブロック・ショー(by Fable 5)

実車の資料(逆ハン/スリップアングル/180°ターンの手順)を元に、ドリフトの目的別ロジックを実測しました。

### 正直な結論: ラップ速度ではグリップが最速
3値操舵(左/中/右)では、誘発ドリフトは横流れで膨らむ分を取り戻せず、**純グリップ走行に速さで勝てません**
(全30コースで 完走27→24、総走行距離も減少。超ヘアピンでも同等以下)。これは実車でも同じで、ドリフトは
ラップタイムでグリップに負け、競技は採点制です。**最速を狙うなら車種別の Fable Racing Line(グリップ系)が正解。**

### ドリフトが本当に強い場面
- **drift-wall-blocker.ino(ライン占有=1位を狙う racecraft)** … ドリフトでテールを左右に流し、車幅で
  走行ラインを塞ぐ。単純な低速ブロックでは隙間ができて抜かれるコースで完封できる。
  実測(賢い追い越し車を抑えた割合・低いほど成功): スピードウェイ 99%→**4%** / ボトルネック 99%→**2%**。
  ※ 大きく開けたオーバルでは振り過ぎてライン開放(95%)。単純ブロックと相補的でコースで使い分ける。
- **drift-showtime.ino(エンタメ/おまけ)** … 速さでなく魅せる用。「ドリフト広場 (ショー会場)」コースで
  全ロックの連続ドーナツを左右に切り替えて 8 の字。平均スリップ 0.58 で 70 秒以上継続。一人称下のスモークと
  横向き姿勢(逆ハン描画)を楽しめる。

→ **目的が変われば最適なドリフトも変わる。** 速さ=グリップ、抜かせない=Drift Wall、魅せる=Showtime。
