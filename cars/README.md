# cars — 車種カタログ

- `cars/community/*.json` — **利用者が投稿した独自車種** (車種 def 形式)

[RumiCar Simulator](https://www.rumicar.com/simulator/) は起動時に `cars/community/` を読み込み、
車種の選択肢に **「🌐 名前」** として追加します。誰でも選んで走らせ、再利用できます。

組込の6車種 (ノーマル FR/FF/4WD・ドリフト FR/FF/4WD) はシミュレータ本体に入っており、
ここには含まれません。このフォルダは**投稿されたものだけ**が入ります。

## 車種を投稿する (PR)

1. シミュレータの「車種」パネルで「車種を追加」を開き、フォームまたは JSON でパラメータを決める
2. 走らせて納得いくまで調整する
3. 「🌐 共有」ボタンを押す → GitHub の新規ファイル作成画面が JSON 入りで開きます
4. そのままコミットするとプルリクエストが作成されます (書込権限が無い場合は自動で fork されます)
5. マージ後、全利用者の車種一覧に表示されます

## フォーマット

`key` と `name` が必須で、あとは省略すると**ノーマル FR の値で埋まります**。一部だけ指定しても動きます。

```json
{
  "key": "custom_lightweight_fr",
  "name": "軽量ライトウェイトFR (投稿例)",
  "mass": 900,
  "accel": 1.18,
  "os": 0.12,
  "powerOs": 0.34,
  "drift": null
}
```

実例は [`community/example-community-car.json`](community/example-community-car.json) にあります。

### パラメータ

| キー | 範囲 | 意味 |
|---|---|---|
| `mass` | 200〜3000 | 車重(kg)。重いほど旋回でアンダー(慣性)・制動が伸びる |
| `accel` | 0〜3 | 加速の倍率。大きいほど速く目標速度へ |
| `brake` | 0〜3 | 制動の倍率。大きいほど短く止まる |
| `maxSpeed` | 0〜2 | 最高速の倍率 (基準 0.7 m/s に対する比) |
| `spin` | 0〜2 | 発進ホイールスピン量。大きいほど発進で空転し加速が鈍る (FF大/4WD≈0) |
| `yawGain` | 0〜3 | 旋回ヨーの基本倍率 |
| `us` | 0〜2 | 定常アンダーステア量。大きいほど高速で曲がりにくい |
| `os` | 0〜2 | 定常オーバーステア量。大きいほど高速で巻き込む |
| `powerUs` | 0〜2 | アクセルON時に増すアンダー (FF: 前輪が駆動+操舵で飽和) |
| `powerOs` | 0〜2 | アクセルON時に増すオーバー (FR: パワーオーバーステア) |
| `liftOffOs` | 0〜2 | アクセルOFF旋回で増すオーバー (タックイン) |
| `brakeOs` | 0〜2 | 制動中に増すオーバー (前荷重でリアが軽い。FR顕著) |
| `slide` | 0〜1 | 通常時の横滑り量 |
| `drift` | — | ドリフト設定。`null` = 滑らない |

数値はすべて有限数である必要があります (`null` や `NaN` は不正)。範囲外の値は保存時に弾かれます。

### ドリフトさせる場合

`drift` にオブジェクトを与えると、省略した項目はドリフト FR の既定値で埋まります。

```json
{
  "key": "custom_drift_special",
  "name": "投稿ドリフト車",
  "drift": {
    "trigger": "power",
    "grip": 0.85,
    "gain": 6.0,
    "minSp": 0.20,
    "slipYaw": 1.10,
    "slipSlide": 0.90,
    "attack": 8.0,
    "release": 4.0,
    "brakeDrift": false
  }
}
```

| キー | 範囲 | 意味 |
|---|---|---|
| `trigger` | `"power"` / `"liftoff"` | 滑り出す契機。`power` = 踏み過ぎ (FR/4WD)、`liftoff` = 急に抜く (FF) |
| `grip` | 0〜1.5 | この駆動力を超えると滑り出す閾値 |
| `gain` | 0〜12 | 滑りの増え方 |
| `minSp` | 0〜2 | 滑り出しに要する最低速度 |
| `slipYaw` | 0〜3 | 滑走中に増える回頭量 |
| `slipSlide` | 0〜2 | 滑走中の横流れ量 |
| `attack` | 0〜20 | 滑り出しの速さ |
| `release` | 0〜20 | グリップ回復の速さ。大きいほど御しやすい |
| `brakeDrift` | 真偽値 | 制動でもドリフトを誘発するか |

## ルール (ゆるく)

- **上書きせず別名で**追加してください。`key` は組込6種 (`normal_fr` / `normal_ff` / `normal_awd` / `drift_fr` / `drift_ff` / `drift_awd`) と重複させないでください
- 不要になったファイルの**削除は GitHub 上**で行います
- 極端なパラメータ (異常に軽い・速い) は他の投稿と一緒に走らせたとき成立しなくなります。まずシミュレータで走らせて確認してください
